## 🚀 Overview
**AgriPulse COOL** is an end-to-end intelligent agricultural vision system designed for autonomous crop health monitoring and precision process control. By combining **OpenCV 5** with **AWS Graviton** and the **Cloud-Optimized OpenCV Library (COOL)**, AgriPulse achieves high-throughput, low-latency image processing while drastically reducing cloud compute costs.

---

## 🛠️ Architecture & Special Features
1. **Perception (OpenCV 5):** Leverages OpenCV 5's upgraded core modules for fast image normalization, adaptive thresholding, and contour analysis.
2. **Cloud Optimization (COOL on AWS Graviton):** Configured to run on ARM-based AWS Graviton instances using COOL for accelerated matrix operations.
3. **Agentic Vision Loop:** Implements a perception-decision-action loop where visual metrics automatically trigger intelligent actuator responses (e.g., precision irrigation valves).
